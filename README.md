# Launchpad

A simple, customizable bookmark launchpad for organizing and opening frequently used links.

## Version 0.4.1

Small visual refinement to the v0.4.0 responsive-grid release.

### Change

- Removed the horizontal divider line above subfolders for a cleaner, more minimal card layout.

### Retained from v0.4.0

- Responsive centered grid
- Equal-height cards sized for roughly 10 bookmark rows, with subtle internal scrolling
- Larger Launchpad wordmark with Lucide Rocket icon
- Mixed ordering of root bookmarks and subfolders
- Bookmark and subfolder drag/drop
- Collapsible subfolders
- Existing data migration, appearance settings, import, search, themes, and font controls

## Deployment

Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root. GitHub Pages can continue to deploy from the `main` branch and `/ (root)`.
